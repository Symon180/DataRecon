# Sicurezza e Perimetri - DataRecon

## 1. Dati e Privacy
- Questo repository è destinato alla pubblicazione open-source sul profilo GitHub di Simone.
- **Divieto assoluto** di inserire nel repository o nei dati di test riferimenti, ragioni sociali, codici clienti, POD/PDR o tracciati provenienti dal contesto lavorativo.
- Tutti i file di esempio e di test devono essere generati sinteticamente (`CODICE/SVILUPPO/genera_dati_esempio.py`) con nomi e importi fittizi.

## 2. Segreti e File Locali
- Nessun token, credenziale o chiave API va mai scritto nel codice o committato.
- I file generati durante le prove manuali e gli screenshot di verifica risiedono in `.local/`, esclusa da Git tramite `.gitignore`.
